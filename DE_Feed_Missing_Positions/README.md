## Перед загрузкой
1. **`H3-5FMC-FAD4` (масло рукколы).** Масло Eruca sativa содержит много эруковой кислоты, а в ЕС для пищевых продуктов действуют предельные значения (VO (EU) 2019/1870). Поэтому оно вынесено в отдельный файл. Нужен лабораторный анализ и допуск как пищевого продукта; значения «Zutaten» в шаблоне для него нет в списке («Rucolasamenöl» отсутствует), поле оставлено пустым.
2. **Пищевое масло `GO-HRO6-WM8V`:** на этикетке DE нужны данные по LMIV (Nährwerttabelle, MHD, ответственный в ЕС). Таблицу питательных веществ в фид не вносил (в ТТХ её нет).
3. **Цены** EUR = UK GBP × 1.1557 (коэффициент из живых DE-офферов; у `2M-RLDD-XQAY` не сходится). Количество = UK; у неактивных на UK оно может быть 0, тогда на DE листинг тоже будет неактивен.
4. **SPF `B8-S7B1-XUBY`:** заявление LSF 50+ и UVA/UVB требует протокола испытаний и CPNP; «водостойкий» и «reef safe» не заявлены.
5. **Гидролат `R1-RAXF-Z5I9`:** `Form des Artikels` и `Duft` пусты (в списках шаблона нет подходящих значений: спрей, ладан), `Enthält Adstringens` = Nein по составу.
6. **Haaröl / Haarspülung:** Browse Node пуст (для SHAMPOO в шаблоне только «Shampoos»).
7. **`BF-UJUW-N586`:** в ТТХ состав (6 масел) расходится с «Преимуществами» (7 масел); использован состав.
